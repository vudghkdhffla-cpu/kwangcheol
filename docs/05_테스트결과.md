## 1. 이전 작업 기록 — 저장 연결 전

기존 코드와 완료 기록이 없어 EPIC 1을 선택했다. React·TypeScript·Vite 프로젝트, 기초 정보·판매 관리·메뉴 수익성 화면과 입력/계산 검증 코드를 준비했다. 기존 운영 JSON·엑셀을 앱에 자동 탑재하지 않았다.

`01_PRD.md`의 사용 환경과 `03_TRD.md` D09의 저장 방식은 아직 미정이다. 실제 저장 방식을 임의로 확정하지 않도록 사용자에게 다음 질문을 전달했다.

- A: 같은 컴퓨터·같은 브라우저에 기록 저장.
- B: 여러 기기에서 사용할 서버 저장.

답변 상태: 대기. 현재 저장 모듈은 명시적으로 저장을 거부하며 저장 버튼을 막아 두었다. 이 상태는 실제 저장 구현 또는 S01~S04 완료가 아니다. 운영에 사용할 수 있는 완성품이 아니다.

FRD D02(원가 누락 판매 허용), D03(판매 당시 원가·수수료), 입력 세부 기준도 미정이다. 계산 코드는 검토용 제안을 가정한 검사만 수행했으며 정책 합의와 실제 저장 연결 이후 기능 검사를 완료해야 한다.

- 과거 원가 재계산을 명시적으로 선택한 경우에만 기초 정보 변경 시 과거 판매의 원가를 다시 계산한다. 보존을 선택하면 판매 당시 원가를 유지한다. 메뉴·채널·판매일 변경 또는 원가 미완료 판매를 명시적으로 수정하면 해당 판매의 근거를 다시 확인한다.
- 서버 저장 선택은 실제 구현된 기능처럼 표시하지 않는다. 서버 저장이 필요하다는 선택에는 별도 설계 필요를 안내하고 브라우저 저장을 승인한 것으로 간주하지 않는다.
- 기술 선택은 TRD의 IndexedDB·Dexie를 구현했다. 원본 PRD·FRD·TRD의 미정 업무 기준을 전역 합의로 수정하지 않았다. 개발자 검사 환경에서 선택한 값도 사용자 승인으로 간주하지 않는다.
- 판매·메뉴 목록은 페이지당 20개를 표시한다. 날짜는 선택한 양끝 날짜를 포함하고 검색은 목록만 좁힌다. 상단 지표는 선택 기간 전체 기록 합계임을 안내한다.
